# machines/

Perfiles opcionales y específicos de un equipo (por ejemplo, desactivar un panel táctil defectuoso).
Se activan con `./instalar.sh --profile <nombre>` y se instalan como `~/.config/dotifails/machine.sh`.
Nada aquí se aplica a otras máquinas. Las preferencias de Hyprland propias del equipo (monitores, rutas personales)
viven en `~/.config/wysun/local.lua`; hay una plantilla en `config/.config/wysun/local.lua.example`.
