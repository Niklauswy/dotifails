# Etapa 1 · Plan 03 — Una sola fuente de tokens (Python y shell) · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `apps/wysun/wysun_core/tokens.json` pasa a usar los nombres y valores del shell
(`rounding`, `spacing`, `padding`, `anim`, `font`) y es la única fuente: el plugin C++ la lee al
arrancar, `Colours.qml` toma de ella su paleta de respaldo y todas las apps Python (Music, Files,
Player, PDF, instalador, Recorder) usan esos nombres, Google Sans Flex y CaskaydiaCove.

**Architecture:**

- **Datos** (`tokens.json`, `schema: 3`): grupos anidados con los nombres del shell. Python los
  aplana con puntos (`rounding.medium`, `font.body.medium.size`), el mismo camino que en QML
  (`Tokens.rounding.medium`). Las plantillas QSS usan `@rounding.medium`; los colores siguen
  planos (`@accent`, `@accent/40`).
- **Shell:** el instalador copia `tokens.json` a `$XDG_DATA_HOME/wysun/theme/tokens.json`. El
  singleton `TokenConfig` del plugin deja de ser un archivo de usuario (`shell-tokens.json` con
  capas por monitor) y se carga una vez de esa ruta: `rounding`, `spacing`, `padding`,
  `anim.durations` y `anim.curves` entran en `appearance.*`. Lo que no está en el JSON queda con
  los valores de `tokens.hpp`, que son el respaldo. `Colours.qml` lee la misma ruta y usa
  `palettes.<modo>.scheme` mientras no exista `scheme.json`.
- **Paridad:** `tests/test_shell_tokens.py` lee los valores de `tokens.hpp` y de
  `appearanceconfig.hpp` (escala tipográfica y familias) y los compara con el JSON.

**Tech Stack:** Python 3.13, PySide6 6.8, C++20/Qt 6.9.3 (plugin `Wysun.*`), QML/Quickshell, unittest.

**Spec:** `docs/superpowers/specs/2026-10-24-wysun-limpieza-base-comun-design.md` §3 y
«Decisiones tomadas» (mandan los tokens del shell; Google Sans Flex y CaskaydiaCove; el cambio
visual en Python está aceptado).

## Esquema de `tokens.json` (schema 3)

```jsonc
{
  "schema": 3,
  "wallpaper": "purple-abstract-3840x3840-27445.jpg",
  "rounding": {"extraSmall": 4, "small": 8, "medium": 12, "large": 16, "largeIncreased": 20,
               "extraLarge": 28, "extraLargeIncreased": 32, "extraExtraLarge": 48, "full": 2147483647},
  "spacing":  {"extraSmall": 4, "small": 8, "medium": 12, "large": 16, "largeIncreased": 20,
               "extraLarge": 28, "extraLargeIncreased": 32, "extraExtraLarge": 48},
  "padding":  { …mismos ocho valores que spacing… },
  "font": {
    "family": {"sans": "Google Sans Flex", "mono": "CaskaydiaCove NF", "icon": "Material Symbols Rounded"},
    "headline": {"large": {"size": 32, "weight": 500}, "medium": {"size": 28, "weight": 500}, "small": {"size": 24, "weight": 500}},
    "title":    {"large": {"size": 22, "weight": 500}, "medium": {"size": 16, "weight": 500}, "small": {"size": 14, "weight": 500}},
    "body":     {"large": {"size": 16, "weight": 400}, "medium": {"size": 14, "weight": 400}, "small": {"size": 12, "weight": 400}},
    "label":    {"large": {"size": 14, "weight": 500}, "medium": {"size": 12, "weight": 500}, "small": {"size": 11, "weight": 400}},
    "mono":     {"large": {"size": 16, "weight": 400}, "medium": {"size": 14, "weight": 400}, "small": {"size": 12, "weight": 400}}
  },
  "anim": {
    "durations": {"small": 200, "normal": 400, "large": 600, "extraLarge": 1000,
                  "expressiveFastSpatial": 350, "expressiveDefaultSpatial": 500, "expressiveSlowSpatial": 650,
                  "expressiveFastEffects": 150, "expressiveDefaultEffects": 200, "expressiveSlowEffects": 300},
    "curves": {"emphasized": [0.05, 0, 0.1333…, …], … las doce curvas de AnimCurves …},
    "lift": 6
  },
  "border": {"width": 1, "focus": 2},
  "icon": {"size": 18, "stroke": 1.8},
  "palettes": {"dark": {"material": "glass", "translucent": true, "colors": {…}, "external": {…}, "scheme": {…120 roles M3…}},
               "light": {"material": "pearl", "translucent": false, …}}
}
```

- Tamaños de letra en **puntos** (`QFont.setPointSizeF`; en QSS `14pt`), como el shell: el texto
  de las apps mide lo mismo que en la barra (decisión del coordinador, opción A).
- `border`, `icon` y `anim.lift` solo los usan las apps Python; no tienen equivalente en el shell.
- `palettes.<modo>.scheme` es el esquema M3 (claves de `scheme.json` → `colours`) que genera
  `wysun_scheme.generate_dynamic` con el fondo por defecto en ese modo; una prueba lo regenera.
- Se borran `shadow_*`, `motion_pulse`, `lock_enter/exit` (sin consumidores) y
  `appearance.fontSize` del plugin (`FontSizeTokens`, sin consumidores).

**Tabla de sustitución (Python, sin alias):**

| Antes | Después |
|---|---|
| `radius_s` (7) | `rounding.small` (8) |
| `radius_control` (10), `radius_m` (12) | `rounding.medium` (12) |
| `radius_l` (20) | `rounding.largeIncreased` (20) |
| `corner_xs/s/m/l/xl/full` | `rounding.extraSmall/small/medium/large/extraLarge/full` |
| `corner_none` | literal `0` (sin redondeo; no es un token del shell) |
| `space_xs/s/m/l/xl` | `spacing.extraSmall/small/medium/large/extraLarge` (xl: 24 → 28) |
| `border`, `focus_width` | `border.width`, `border.focus` |
| `font_family`, `font_mono` | `font.family.sans`, `font.family.mono` |
| `font_caption/small/body/heading/title` (px) | `font.label.small/body.small/body.medium/title.medium/title.large` (pt) |
| `motion_enter/exit/fast` | `anim.durations.expressiveFastSpatial/small/expressiveFastEffects` |
| `motion_easing` (`OutCubic`) | `anim.curves.emphasizedDecel` (`qt_theme.easing(name)`) |
| `motion_lift`, `icon_size`, `icon_stroke` | `anim.lift`, `icon.size`, `icon.stroke` |

Los roles de texto (`text_font('body')`, `font(role='body')`, `M['font_'+role]`) pasan a los
nombres del shell (`'body.medium'`). Los nombres de esquina de `wysun_media.shape`
(`'xs'…'full'`) pasan a `'extraSmall'…'full'`; `'none'` desaparece (se pasa `0`).

## Global Constraints

- NO desplegar (`./instalar.sh`), NO reiniciar quickshell ni Hyprland, NO cerrar ventanas.
- Compilar el plugin solo con `python3 installer/runtime_build.py --prefix ~/.cache/wysun-worker-etapa1-03/runtime --cache ~/.cache/wysun-worker-etapa1-03/cache`
  (nunca el prefijo ni la caché por defecto); se borra al terminar.
- Sin compatibilidad: ni alias de nombres viejos ni lectura de `shell-tokens.json`.
- No tocar `apps/shell/components/` ni `apps/shell/modules/` (otro worker, rama `etapa1-06-qml`).
  Se tocan `services/Colours.qml`, `shell.qml` y el plugin.
- Toda UI sigue tomando valores de tokens (`tests/test_theme_literals.py`); los arreglos de
  recorte por el cambio a puntos se derivan de métricas de fuente o tokens, nunca de literales.
- Procedencia: cabeceras «Derivado de…», `THIRD_PARTY.md`, licencias en `LICENSES/`.

## Decisión de fuentes

- **Google Sans Flex** (OFL-1.1) ya está en `apps/shell/assets/google-sans-flex/` y el shell la
  carga con `FontLoader`. **CaskaydiaCove NF** (Nerd Fonts v3.4.0, `CaskaydiaCoveNerdFont-Regular.ttf`,
  OFL-1.1 de Cascadia Code + MIT del parcheador) no existe en el sistema ni en el repo: hoy el shell
  cae a otra monoespaciada.
- Debian no empaqueta Google Sans Flex ni CaskaydiaCove (solo `fonts-cascadia-code`, sin Nerd
  Font), así que **se empaquetan**: `wysun_core/fonts/` (apps, instalador y cada release del
  Recorder) y `apps/shell/assets/fonts/` (el shell se instala aparte y puede ir sin las apps). Es el
  mismo patrón que Material Symbols; una prueba exige que las copias sean idénticas.
- Se borran `Rubik-Variable.ttf` y `LICENSES/OFL-Rubik.txt` del kit (ningún consumidor tras el cambio).

## Review Focus

1. **Instalación limpia sin `tokens.json` instalado** (shell desplegado antes que las apps o
   archivo borrado): el shell debe arrancar con los valores de `tokens.hpp` y avisar en el log, sin
   toast ni bloqueo. Lo cubre la prueba QML de Task 4 con `XDG_DATA_HOME` vacío.
2. **Un `tokens.json` con un valor de otro tipo** (`"small": "8"`): el plugin conserva el
   respaldo de esa clave y no aborta. Lo cubre la prueba QML de Task 4.
3. **Texto más grande (pt)**: botones, filas y cabeceras de altura fija no deben recortar texto.
   Lo cubre la revisión con capturas offscreen de Task 3 (claro y oscuro).
4. **Release del Recorder**: debe llevar las fuentes nuevas dentro de su `wysun_core` y no
   depender de Rubik. Lo cubre `test_core_packaging` (Task 2).
5. **`Colours.qml` sin `scheme.json`**: debe pintar la paleta base del modo (no negro ni rosa).
   Lo cubre `test_colours_fallback_comes_from_tokens` (Task 5).
