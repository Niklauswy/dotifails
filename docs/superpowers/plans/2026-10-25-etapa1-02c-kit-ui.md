# Etapa 1 · Plan 02c — Kit de widgets en `wysun_core.ui` · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El kit Material de widgets Qt sale de `wysun_music/ui` a `wysun_core/ui`. Music, Files,
Player (`media_host`), el instalador y el Recorder lo importan desde allí. Se borran el
reexportador `wysun_files/kit.py`, las piezas duplicadas de `loomrec/ui/app_kit.py`, las tres
copias de Toast, las cuatro de la ventana sin bordes y las dos copias de las fuentes empaquetadas.

**Architecture:** el paquete `wysun_core/ui/` (PySide6) tiene estos módulos:

| Módulo | Contenido |
|---|---|
| `fonts` | fuentes empaquetadas y familias |
| `style` | métricas, tipos, símbolos, duraciones |
| `shapes` | formas M3 |
| `widgets` | botones, chips, slider, etiquetas |
| `panels` | `Panel`, navegación, búsqueda |
| `toast` | `Toast` |
| `frameless` | mover y redimensionar ventanas sin bordes |

Las fuentes viven en `wysun_core/fonts/`, así llegan al Recorder (por el enlace y cada release)
y al instalador (`ui_runtime`) sin copias.

**Principio:** se **mueve** código que ya existe y funciona; no se rediseña. Donde dos copias
difieren, gana la de Music (la más usada), salvo que el ledger razone lo contrario. Lo que solo
usa una app se queda en esa app.

**Tech Stack:** Python 3.13, PySide6 6.8, unittest.

**Spec:** `docs/superpowers/specs/2026-10-24-wysun-limpieza-base-comun-design.md` §2 (`ui`,
`icons`/`fonts`).

```python
# wysun_core/ui/frameless.py
RESIZE_MARGIN = 6
def resize_edges(widget, point) -> Qt.Edges
class FramelessResize:                  # mixin for a top-level QWidget
    drag_height = 72                    # each window sets its own value: today's literal in its mousePressEvent
    def mousePressEvent(self, event)    # edges → startSystemResize; y < drag_height → startSystemMove; else super()
    def mouseMoveEvent(self, event)     # resize cursors on the edges, else super()
```
