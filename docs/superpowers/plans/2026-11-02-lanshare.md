# Wysun LANShare (rediseño) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the LANShare redesign: new CLI (several paths, `--subidas`, `--clave`, idle shutdown, `--detener`), a status contract, a new light Wysun web UI, a bar indicator with a popout, and «Compartir en la red» in Files.

**Architecture:**
- The server is split into small stdlib modules inside `wysun_lanshare`: options, shared roots, access gate, activity, status file, web theme, media and HTTP handler.
- The shell reads `$XDG_RUNTIME_DIR/wysun-lanshare/*.json` through a `LanShare` singleton (FolderListModel plus FileView) and shows a status icon. The icon opens a bar popout, the same mechanism Network and Bluetooth use, so there is no plugin rebuild.
- Files launches the server detached with the system Python.

**Tech Stack:** Python 3 stdlib plus `wysun_core`/`wysun_services`, vanilla JS/CSS, and Quickshell QML. The Files QML runs on PySide6.

**Spec:** `docs/superpowers/specs/2026-11-01-lanshare-design.md`

## Global Constraints

- Uploads are off by default. Without `--subidas` the server returns 403 on upload and mkdir. `--subidas` works only with one folder; with anything else it is a clear error.
- `--clave` with no value generates 6 characters from `abcdefghijkmnpqrstuvwxyz23456789`, which leaves out l, 1, o and 0.
  - A session is an `HttpOnly` cookie, random, valid while the server lives.
  - Failed tries are limited per IP: 5 failures block that IP for 60 s.
- Port: 8000 by default. If it is taken, try up to +20 and say which one is used. `-p/--port` and `--readonly` are accepted as old aliases; `--readonly` changes nothing.
- Shutdown: after `--inactivo` (default 1 h) with no request from an authorised client and no transfer in progress. `--sin-limite` disables it.
- Status file `$XDG_RUNTIME_DIR/wysun-lanshare/<pid>.json`:
  - The directory has mode 0700 and each write is atomic.
  - It is written at most about once per second, plus a heartbeat every 10 s. It is deleted on exit.
  - The shell treats a file whose `updated` is more than 30 s old as dead.
- The web page is always light, with colours from the wallpaper in light mode. Fonts come from `wysun_core/fonts`, served by the server, so nothing loads from the internet. The CSS uses only variables the server generates.
- Nothing from yurai remains: no brand, no channels, no `describe()`.
- Shell UI uses `Colours`/`Tokens` only. QML/JS/PY carry no literal colours (`tests/test_theme_literals.py`).
- `bin/wysun` stays the only entry point (`wysun lanshare`). Tests run in a temporary HOME/XDG. Builds and suites run one at a time.

## Review Focus

- Two shared items with the same name (`a/foto.jpg`, `b/foto.jpg`) must both be reachable, as `foto.jpg` and `foto (2).jpg` (Task 2).
- A symlink inside a shared folder that points outside it must be neither listed nor served (Task 2).
- A client without a cookie that hits `/raw/…` or `/api/ls` gets 401 and does not count as activity (Task 4).
- `--detener` with a PID that is not a LANShare, such as the shell's own PID, sends no signal (Task 3).
- A long download in progress stops the idle shutdown even after the deadline (Task 3).

### Task 2: Shared roots (virtual list and confinement)

**Files:**
- Create: `apps/python/wysun_lanshare/share.py`
- Test: `tests/test_lanshare_share.py`

**Interfaces:**
- Produces:
  - `Share(paths: list[str])` has the attribute `mode` ('folder' | 'list') and `title` (the folder name, or «N elementos»).
  - `resolve(rel) -> str|None`: the real path. It returns None for `..`, hidden parts, symlinks that escape, and the virtual root itself.
  - `listing(rel) -> list[dict]` raises `LookupError`. Each dict has `name, kind, mtime`, plus `size` or `count`.
  - `is_dir(rel)`, `zip_members(rel) -> iterator[(real, arcname)]`, `zip_name(rel) -> str`, `display(rel) -> str` (for notifications).
- In folder mode `rel` is relative to the folder. In list mode the first segment is the virtual name and the rest is confined to that root. `''` is the virtual list.
- Move `kind_of`, `clean_name` and `unique_name` here from `server.py`.

- [ ] Tests:
  - Folder mode lists without hidden entries.
  - An escaping symlink is neither listed nor resolved.
  - `../x` gives None.
  - List mode with two files of the same name shows `foto.jpg` and `foto (2).jpg`, and both resolve.
  - A folder in the list can be walked and its symlink escape is blocked.
  - `''` resolves to None in list mode, but `listing('')` gives the items.
  - `zip_members('')` in list mode covers everything.

### Task 3: Activity, status file and `--detener`

**Files:**
- Create: `apps/python/wysun_lanshare/status.py`
- Test: `tests/test_lanshare_status.py`

**Interfaces:**
- Produces:
  - `Activity(idle: int|None, clock=time.time)` has these methods:
    - `touch(ip, agent)`
    - `begin(ip, name, total, direction) -> id`, `advance(id, n)`, `end(id)`
    - `deadline() -> float|None`, `expired() -> bool` (False while a transfer runs)
    - `clients() -> list[{ip, device, seen}]` (last 5 min)
    - `transfers() -> list[{ip, device, name, done, total, direction}]`
    - `version` (an int that increases on every change)
  - `device_of(user_agent) -> str` returns 'iPhone' | 'iPad' | 'Android' | 'Windows' | 'Mac' | 'Linux' | 'Navegador'.
  - `status_dir(environ=os.environ) -> Path` is `$XDG_RUNTIME_DIR/wysun-lanshare`, falling back to `/run/user/<uid>`.
  - `StatusFile(pid, base_info: dict)` has `.write(activity)` (throttled to 1/s unless forced; it adds `updated`, `clients`, `transfers`, `shutdownAt`) and `.remove()`.
  - `stop(pid) -> bool`: true only if `/proc/<pid>/cmdline` contains `wysun_lanshare`, the owner is the current uid, and SIGTERM was sent.
  - `prune()` deletes files of dead PIDs.

- [ ] Tests (fake clock):
  - After `idle` seconds with no touch, `expired()` is True. With an open transfer it is False even after the deadline.
  - `idle=None` means `deadline()` is None.
  - The status file goes in a temporary `XDG_RUNTIME_DIR`, the directory has mode 0700, the JSON has `pid, paths, addresses, port, password, uploads, clients, transfers, shutdownAt, updated`, and `remove()` deletes it.
  - `stop(os.getpid())` is False, because the test runner is not LANShare.
  - `stop` of a child `python3 -c 'import time; time.sleep(30)' wysun_lanshare` is True and the child dies with SIGTERM.
  - `prune` removes the file of a dead PID.
- [ ] Implement, run, commit.

### Task 4: Server (gate, theme, routes) and `main`

**Files:**
- Create: `apps/python/wysun_lanshare/media.py` (probe, thumbs and sprites, moved unchanged), `apps/python/wysun_lanshare/webtheme.py`, `apps/python/wysun_lanshare/net.py`
- Modify: `apps/python/wysun_lanshare/server.py` (rewrite), `bin/wysun` (help line), `docs/utilities.md`
- Test: `tests/test_lanshare_server.py` (a real server on 127.0.0.1 in a thread, temporary HOME/XDG)

**Interfaces:**
- Produces:
  - `Gate(password: str|None, clock)` has `check(ip, attempt) -> token|None|'blocked'` and `allowed(cookie_header) -> bool`.
  - `webtheme.css(home=None) -> str` returns `:root{--m3<role>:#..; --rounding-*; --spacing-*; --font-*; --anim-*}` and `@font-face` rules.
    - Its colours are the light scheme: `scheme.json` if its mode is light; else `generate_dynamic(wallpaper, mode='light')`, cached in `~/.cache/wysun/lanshare/scheme-<hash>.json`; else `palettes.light.scheme`.
  - `net.addresses() -> list[{name, ip}]` (from `ip -j -4 addr`, LAN interfaces, no loopback) and `net.easy_name(port) -> str|None` (`http://HOST.local:PORT` only when `/run/avahi-daemon/socket` exists).
  - `make_server(options) -> (srv, port)` tries port … port+20. `run(options)` prints, writes status and handles SIGTERM/SIGINT.
- Routes:
  - `GET /` serves the page.
  - `/static/*`, `/fonts/<file>.ttf` and `/theme.css` are always public.
  - `POST /api/login` (JSON `{clave}`) sets the cookie `ls=…; HttpOnly; SameSite=Lax; Path=/`.
  - `GET /api/info` gives `{host, title, mode, uploads, locked}`. `locked` means a password is required and this client lacks the cookie.
  - These need the cookie when there is a password: `GET /api/ls?path=`, `/api/thumb|sprite?path=`, `/raw/<rel>[?dl=1]` (with Range), `/zip/<rel>` (`/zip/` is everything), `PUT /api/upload?dir=&name=` and `POST /api/mkdir`.
- The handler calls `activity.touch` only for authorised requests, and wraps `/raw`, `/zip` and uploads in `begin`/`advance`/`end`.
- A finished upload runs `notify-send -a "Wysun LANShare" "Archivo recibido" "<nombre> · <carpeta>"`, but only if `shutil.which('notify-send')`.

- [ ] Tests:
  - Without a password, `/api/ls` lists and `/raw/x.txt` with `Range: bytes=0-1` gives 206 and two bytes.
  - Upload without `--subidas` gives 403; with it, 200 and the file is written.
  - With a password, `/api/ls` without the cookie gives 401 and `activity.version` does not change. The wrong password 5 times gives 429. The right one gives `Set-Cookie` with HttpOnly, and with that cookie the request succeeds.
  - `/theme.css` contains `--m3primary` and `@font-face`, and has no `http`.
  - `/zip/` in list mode returns a valid zip with both items.
  - Port: with 8000 taken, `make_server` picks a later free one (use an ephemeral base port in the test).
  - `--detener` from `main` calls `status.stop`.
- [ ] Implement, run, commit.
